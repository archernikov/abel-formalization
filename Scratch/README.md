# Development archive

These files preserve earlier experiments, intermediate proofs, and targeted
checks made during the formalization. Some are superseded by the final library
or use older declaration names. They are retained as project history and are
not imported by the public `AbelFormalization.lean` library.

For the verified development and current audits, follow the build instructions
in the repository's top-level README. Files here are not promised to compile
individually against the final library.
